## Featured project

### [EnterpriseERP](https://github.com/SHAKIL-AI-Engineer/EnterpriseERP)

A garments ERP project combining a **Next.js frontend**, **ASP.NET Core services**, and selected **Go services**.

- **Business domains:** HR, attendance, leave, payroll, production, merchandising, inventory, and accounts.
- **Architecture:** YARP API gateway, shared building blocks, and a gradual migration from a legacy API to domain services.
- **Data and infrastructure:** SQL Server, Redis, RabbitMQ, and Docker Compose.
- **Current focus:** improving service boundaries, documentation, reliability, and the developer experience.
